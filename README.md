# 2ヶ月スケジュール（ホワイトボード形式）

Google Apps Script Webアプリとして動作する、スプレッドシートをDBにした2ヶ月ホワイトボードUI。

## 機能概要

- **表示**: 当月＋翌月の予定をホワイトボード形式で表示
- **権限制御**: viewer（閲覧のみ）/ editor・admin（当月＋翌月のみCRUD可）
- **過去閲覧**: 過去月の予定を一覧表示（閲覧のみ）

## ファイル構成

```
gas/
├── Code.gs      # バックエンド（GAS）
├── index.html   # メインHTML
├── styles.html  # CSS
└── app.html     # JavaScript
```

## デプロイ手順

### 1. スプレッドシートの準備

提供されたExcelテンプレートをGoogleスプレッドシートとしてインポート、または新規作成。

**必須シート**:
- `01_Settings` - 設定（B5:基準月, B6:編集可能月数, B7:タイムゾーン）
- `02_Users` - ユーザー権限（ヘッダー5行目, データ6行目〜）
- `03_Events` - 予定データ（ヘッダー5行目, データ6行目〜）

### 2. Apps Script プロジェクト作成

1. スプレッドシートを開く
2. **拡張機能** → **Apps Script** をクリック
3. 以下のファイルを作成:

| ファイル名 | 種類 | 内容 |
|-----------|------|------|
| Code.gs | スクリプト | `gas/Code.gs` の内容をコピー |
| index.html | HTML | `gas/index.html` の内容をコピー |
| styles.html | HTML | `gas/styles.html` の内容をコピー |
| app.html | HTML | `gas/app.html` の内容をコピー |

### 3. デプロイ

1. Apps Script エディタで **デプロイ** → **新しいデプロイ**
2. **種類** → **ウェブアプリ**
3. 設定:
   - **説明**: 任意（例：2ヶ月スケジュール v1.0）
   - **次のユーザーとして実行**: 自分
   - **アクセスできるユーザー**: 組織内のユーザー（または適切な範囲）
4. **デプロイ** をクリック
5. 表示されたURLをコピー

### 4. ユーザー登録

`02_Users` シートに自分のメールアドレスを登録:

| メールアドレス | 権限 | 有効 | 表示名 |
|---------------|------|------|--------|
| your@email.com | admin | TRUE | 管理者 |

## 動作確認手順

### editor での確認

1. `02_Users` に editor 権限で登録
2. デプロイURLにアクセス
3. 以下を確認:
   - [ ] 当月＋翌月のボードが表示される
   - [ ] 空白セルクリック → 予定追加モーダルが開く
   - [ ] 予定を保存 → ボードに反映される
   - [ ] 予定クリック → 編集モーダルが開く
   - [ ] 予定を編集・保存 → 反映される
   - [ ] 予定を削除 → 消える

### viewer での確認

1. `02_Users` に viewer 権限で登録（別アカウント）
2. デプロイURLにアクセス
3. 以下を確認:
   - [ ] ボードは表示される
   - [ ] セルクリックしても追加モーダルが開かない
   - [ ] 予定クリック → モーダルは開くが編集不可（フィールド無効化）
   - [ ] 保存・削除ボタンが無効

### 過去月の確認

1. 「過去一覧」ボタンをクリック
2. 任意の過去月を選択して「読み込み」
3. 一覧が表示される（編集導線なし）

## トラブルシューティング

### メールアドレスが取得できない

**原因**: GASの実行環境によっては `Session.getActiveUser().getEmail()` が空を返す場合がある。

**対処**:
- デプロイ設定で「アクセスできるユーザー」を組織内に限定
- Google Workspace 環境で使用

### 権限エラー（FORBIDDEN）

**確認事項**:
1. `02_Users` シートにメールアドレスが登録されているか
2. 権限が `editor` または `admin` になっているか
3. 有効フラグが `TRUE` になっているか

### 編集可能期間外エラー（OUT_OF_EDITABLE_RANGE）

**確認事項**:
1. `01_Settings` の B5（基準月）が正しいか
2. 対象日が当月〜翌月末の範囲内か

## 技術仕様

### スプレッドシート構造

**01_Settings**
- B5: 表示基準月（YYYY-MM）
- B6: 編集可能月数（デフォルト: 2）
- B7: タイムゾーン（デフォルト: Asia/Tokyo）
- 行13〜: 予定種別マスタ（code, label, color, sort, enabled）
- 行25〜: ステータスマスタ（code, label, sort, enabled）

**02_Users**
- ヘッダー: 5行目
- データ: 6行目〜
- 列: A(メールアドレス), B(権限), C(有効), D(表示名), E(備考), F(作成日時), G(更新日時)

**03_Events**
- ヘッダー: 5行目
- データ: 6行目〜
- 列: A(予定ID), B(日付), C(開始時刻), D(終了時刻), E(予定種別), F(件名), G(場所), H(メモ), I(表示順), J(状態), K(月キー), L(作成日時), M(作成者), N(更新日時), O(更新者)
